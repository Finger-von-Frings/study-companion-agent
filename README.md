# 学伴 Agent

学伴 Agent 是一个在自己电脑上运行的课程学习工具。选择计算机网络、数据结构或操作系统，输入一个问题，就能查阅相关笔记、查看引用原文，并通过练习和错题复习巩固知识。

## 下载

在本仓库页面点击 **Code → Download ZIP**，把压缩包完整解压到一个可写的文件夹。以下命令都在包含 `app.py` 的目录中运行。

## Windows 启动

安装 Python 3.10 或更高版本。在项目文件夹的地址栏输入 `powershell` 并按回车，运行以下命令。

```powershell
py -3 app.py
```

如果系统找不到 `py`，用 `python --version` 确认版本达到 3.10 后，运行 `python app.py`。

## WSL 启动

在 WSL 终端进入项目目录，确认 Python 版本达到 3.10，然后启动服务。

```bash
python3 --version
python3 app.py
```

两种环境都可以用 Windows 浏览器打开 [学伴首页](http://localhost:8000)。使用期间保持终端开启，结束时在终端按 **Ctrl+C**。前端依赖已随项目提供，启动无需安装 npm 或 pip 包。

## 第一次使用

1. 打开首页，选择「计算机网络」，试着问「TCP 和 UDP 有什么区别？」。在回答中点击引用，查看对应笔记的原文。
2. 点击「出题考我」，提交答案后查看解析。答错的题可以在错题本中重新练习。
3. 想复习自己的笔记时，可以在资料库上传 UTF-8 编码的 Markdown 或 TXT 文件，再选择对应资料提问。`examples/` 中有一份可供试用的笔记。

默认使用离线模式，通过关键词检索课程笔记，并从内置题库选题。聊天、上传资料和练习记录保存在本机项目的 `data/` 目录中。继续学习时，请使用同一浏览器和访问地址。

## 可选：启用 DeepSeek 在线问答

在项目目录中将 `.env.example` 复制为 `.env`（已有该文件时直接编辑），用文本编辑器填写自己的 `DEEPSEEK_API_KEY`，保存后刷新页面。

```dotenv
DEEPSEEK_API_KEY=在这里填写自己的密钥
```

在线提问会将问题、近期对话和检索到的资料片段发送至 DeepSeek，并可能产生 API 费用。请妥善保管 `.env`，分享项目时仅提供 `.env.example`。

## 端口被占用怎么办？

在项目目录的 `.env` 中设置 `PORT=8001`，重新启动服务，然后打开 [本地 8001 端口](http://localhost:8001)。
