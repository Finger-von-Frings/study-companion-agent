# 学伴 Agent

学伴 Agent 是一个在自己电脑上运行的课程学习工具。选择计算机网络、数据结构或操作系统，输入一个问题，就能查阅相关笔记、查看引用原文，并通过练习和错题复习巩固知识。

## 下载

在本仓库页面点击 **Code → Download ZIP**，把压缩包完整解压到一个可写的文件夹。以下命令都在包含 `app.py` 的目录中运行。

## Windows 启动

安装 Python 3.10 或更高版本。在项目文件夹的地址栏输入 `powershell` 并按回车，运行以下命令。

```powershell
py -3 app.py
```

如果系统找不到 `py`，用 `python --version` 确认版本达到 3.10 后，运行 `python app.py`。

## WSL 启动

在 WSL 终端进入项目目录，确认 Python 版本达到 3.10，然后启动服务。

```bash
python3 --version
python3 app.py
```

两种环境都可以用 Windows 浏览器打开 [学伴首页](http://localhost:8000)。使用期间保持终端开启，结束时在终端按 **Ctrl+C**。前端依赖已随项目提供，启动无需安装 npm 或 pip 包。

## 第一次使用：从一篇笔记到一次复习

以「TCP 三次握手」为例。无需配置 API 密钥就能走完下面的流程。左下角显示「离线模式」时，学伴会检索笔记，并从内置题库中选取匹配的题目。

1. **选定笔记。** 打开「我的资料库」，筛选「计算机网络」，找到《TCP 三次握手》。点「原文」可以先读笔记；点「提问」会回到学习工作台，自动选中这份资料，并在输入框里填入一个示例问题。
2. **问一个具体问题。** 将示例问题改成“TCP 三次握手时，客户端为什么还要发送最后一个 ACK？”，选择「直接讲解」，点「发送」。输入时按 Enter 发送，按 Shift+Enter 可以换行。
3. **核对回答。** 点击回答中的编号引用，或打开「回答依据」并点击资料片段。右侧会显示原文并高亮命中的段落。在这篇笔记里，可以找到第三步的“确认号为 y+1”，对照服务端在第二步发出的序号 y。
4. **做一组练习。** 点击这条回答下的「出题考我」。每题选一项，右上角的「已作答」会随之更新。提交前可以改选，此时选中的颜色只表示你点了哪一项。全部选完后点「提交并查看解析」：绿色标出正确答案，红色标出你选错的选项，每题下方都有解析。
5. **重练错题。** 如果刚才有题答错，进入「错题与进度」→「今日待复习」，找到相同的题干，点「复习这一题」。重新答对后，回到「待巩固」可以看到下次复习时间。如果整组全部答对，这次练习只更新统计，不会新增错题。

## 提问时怎样选模式和资料范围？

| 你想做什么 | 界面操作 |
| --- | --- |
| 第一次学一个概念 | 选「直接讲解」。在线时可继续点「举例说明」或「再简单一点」；离线时主要返回匹配的笔记片段。 |
| 希望先自己推理 | 在线时选「引导学习」，例如问“如果第三次 ACK 没有到达，服务端会处于什么状态？”，再根据提示回答。离线时该模式提供检索内容。 |
| 已经复习完，想直接做题 | 选「自我检测」，输入具体知识点并发送。已有讲解时，也可以直接点那条回答下的「出题考我」。 |

输入框旁的资料范围可以选全部资料、一门课程或单篇笔记。跨章节比较时可选整门课程；只想按课堂笔记里的定义作答时，选对应的单篇资料。若找不到相关依据，先检查范围，再试一次笔记里的术语。

## 用自己的课堂笔记提问

1. 在「我的资料库」点击上传区域选择文件，或把文件拖进去。支持 UTF-8 编码的 Markdown（.md）和纯文本（.txt），单个文件不超过 200 KB，最多上传 30 份。
2. 看到文件名后还要点「上传资料」。第一次可以用仓库附带的[《HTTP 状态码速记》](examples/HTTP状态码速记.md)试一遍。
3. 搜索资料名称，在新笔记的卡片上点「提问」，输入“401 和 403 各表示什么？”。回答出现后打开引用，核对笔记中的「常见状态码」和「易错点」。
4. 离线模式可以检索上传的笔记，但练习来自内置题库。如果自写笔记没有匹配的题目，可以继续查原文，或启用下方的在线问答后再出题。

## 继续上次学习与安排复习

- **找回对话。** 下次启动服务后，用同一浏览器打开同一地址，在左侧「最近的学习」点击记录，即可继续查看问答和已提交的练习。「开始新的学习」会开启另一次对话。
- **集中复习。** 在「错题与进度」点「复习到期题（最多 5 题）」可以一次重练多题。连续答对后，复习间隔依次为 1、3、7、14、30 天；想提前练习时，可以在「待巩固」里点「提前巩固」。
- **读懂统计。** 「知识点练习情况」按已提交的题目统计，重练也会计入。聊天、上传资料和练习记录保存在项目的 data/ 目录；需要备份时，先停止服务，再复制整个目录。

## 可选：启用 DeepSeek 在线问答

在项目目录中将 `.env.example` 复制为 `.env`（已有该文件时直接编辑），用文本编辑器填写自己的 `DEEPSEEK_API_KEY`，保存后刷新页面。

```dotenv
DEEPSEEK_API_KEY=在这里填写自己的密钥
```

在线提问会将问题、近期对话和检索到的资料片段发送至 DeepSeek，并可能产生 API 费用。请妥善保管 `.env`，分享项目时仅提供 `.env.example`。

## 端口被占用怎么办？

在项目目录的 `.env` 中设置 `PORT=8001`，重新启动服务，然后打开 [本地 8001 端口](http://localhost:8001)。
