# 数组与链表

关键词：数组 链表 随机访问 插入 删除 指针 连续内存 双向链表

数组在连续内存中存放元素，可以按下标在 O(1) 时间内随机访问；在中间插入或删除元素需要移动后续元素，平均为 O(n)。
链表的结点通过指针相连，不要求连续内存。已知前驱结点时，插入或删除为 O(1)；但按位置查找必须从头遍历，为 O(n)。
单链表只能向后遍历；双向链表的结点同时保存前驱和后继指针，删除给定结点更方便，但每个结点占用更多空间。
数组对 CPU 缓存更友好。频繁按下标读取时适合用数组；频繁在已知位置插入删除时可以考虑链表。不能笼统地说链表插入一定更快，因为先要花 O(n) 找到位置。
