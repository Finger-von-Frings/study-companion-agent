# 算法复杂度分析

关键词：时间复杂度 空间复杂度 大O 渐近分析 最坏情况 平均情况

大 O 记号描述输入规模 n 增大时，运行时间或占用空间的增长趋势（上界），忽略常数系数和低阶项。例如 3n² + 5n + 2 记为 O(n²)。
常见量级从小到大为：O(1)、O(log n)、O(n)、O(n log n)、O(n²)、O(2ⁿ)。二分查找每次把范围减半，为 O(log n)；两层嵌套循环遍历同一数组通常为 O(n²)。
分析时要区分最好、平均和最坏情况。例如快速排序平均为 O(n log n)，最坏为 O(n²)。
复杂度更低并不代表任何规模下都更快：n 很小时，常数因子可能起决定作用。空间复杂度统计算法额外占用的内存，递归的调用栈也要计入。
