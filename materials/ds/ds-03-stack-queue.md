# 栈与队列

关键词：栈 队列 后进先出 先进先出 LIFO FIFO 循环队列 括号匹配

栈只允许在一端（栈顶）插入和删除，遵循后进先出（LIFO）。函数调用、括号匹配、表达式求值和撤销操作都常用栈。
队列在队尾入队、在队头出队，遵循先进先出（FIFO）。打印任务排队、广度优先搜索都常用队列。
用数组实现队列时常采用循环队列，避免出队后前部空间被浪费。一种常见约定是空出一个位置来区分队空和队满：front == rear 表示队空，(rear + 1) % capacity == front 表示队满。
入栈、出栈、入队、出队操作的时间复杂度通常都是 O(1)。
