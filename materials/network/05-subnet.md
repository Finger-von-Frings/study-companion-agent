# IPv4 与子网划分

关键词：IPv4 IP 子网 子网掩码 CIDR 网络地址 广播地址 /24 /26

IPv4 地址长度为 32 位，通常用点分十进制表示。CIDR 的 /n 表示前 n 位是网络前缀，其余是主机位。
例如 192.168.1.0/24 的掩码为 255.255.255.0，共有 256 个地址。对普通广播子网，网络地址为 192.168.1.0，广播地址为 192.168.1.255，通常可分配主机地址 254 个。
将该 /24 等分成四个 /26 子网，每个有 64 个地址，通常有 62 个可用主机地址。四段分别从 .0、.64、.128、.192 开始。
通常主机数公式为 2 的主机位数次方减 2，但 /31 点对点链路和 /32 等情况有特殊含义，不能机械套用。
