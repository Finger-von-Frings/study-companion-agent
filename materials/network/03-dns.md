# DNS 域名解析

关键词：DNS 域名 网址 IP 地址 递归 迭代 缓存

DNS 将域名映射到资源记录，例如 A 记录对应 IPv4 地址，AAAA 记录对应 IPv6 地址。一个域名可以对应多个地址。
客户端通常先检查本地缓存，再向递归解析器查询。递归解析器可使用缓存；没有合适缓存时，通常沿根、顶级域、权威域名服务器逐级迭代查询，最终把结果返回客户端。
TTL 决定记录可被缓存的时间。缓存命中时，并不是每次都要从根服务器重新查询。
传统 DNS 常使用 UDP 53 端口，也支持 TCP 53；不能说 DNS 只使用 UDP。
