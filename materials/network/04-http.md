# HTTP 与 HTTPS

关键词：HTTP HTTPS TLS 请求 响应 状态码 加密 证书

HTTP 是应用层的请求—响应协议。常见方法包括 GET 与 POST；常见状态码包括 200（成功）、404（资源未找到）、500（服务器内部错误）。
HTTP 本身是无状态的，会话可借助 Cookie 等机制实现。
HTTPS 在安全传输机制上承载 HTTP。TLS 提供传输加密、完整性保护和身份认证，服务器证书用于帮助验证服务器身份。HTTPS 不保证网站内容本身可信，也不能防止所有攻击。
HTTP/1.1 与 HTTP/2 通常运行于 TCP 之上；HTTP/3 基于 QUIC，QUIC 使用 UDP。因此“HTTP 永远基于 TCP”不正确。
