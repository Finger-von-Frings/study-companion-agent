# CPU 调度算法

关键词：调度 先来先服务 FCFS 短作业优先 SJF 时间片轮转 RR 优先级 周转时间 饥饿

先来先服务（FCFS）按到达顺序执行，实现简单；但长作业排在前面时，后面的短作业要等很久（护航效应）。
短作业优先（SJF）在所有作业同时到达时可以使平均等待时间最小，但需要预估运行时间，长作业可能一直得不到执行（饥饿）。
时间片轮转（RR）给每个就绪进程分配固定的时间片，用完后排到就绪队列末尾，适合交互式系统。时间片过大时退化为 FCFS，过小则上下文切换开销变大。
优先级调度可能让低优先级进程饥饿，可以用"老化"逐步提高等待已久进程的优先级。
周转时间 = 完成时间 − 到达时间；等待时间 = 周转时间 − 运行时间。
