# 进程与线程

关键词：进程 线程 资源分配 调度 上下文切换 进程状态 就绪 阻塞

进程是正在执行的程序实例，是操作系统进行资源分配的基本单位，拥有独立的地址空间。线程是 CPU 调度的基本单位；同一进程内的线程共享代码、数据和打开的文件，但各自有独立的栈和寄存器。
进程的三种基本状态是就绪、运行和阻塞。时间片用完时，进程从运行回到就绪；等待 I/O 时进入阻塞；I/O 完成后回到就绪，而不是直接进入运行。
线程切换不需要切换地址空间，开销通常比进程切换小。线程共享内存也意味着访问共享数据时需要同步。
多进程的隔离性更好，一个进程崩溃一般不影响其他进程；而同一进程内的某个线程出错，可能导致整个进程退出。
