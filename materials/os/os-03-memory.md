# 分页与虚拟内存

关键词：分页 页表 虚拟内存 缺页 TLB 页面置换 LRU FIFO 逻辑地址 页内偏移

分页把进程的逻辑地址空间划分为固定大小的页，把物理内存划分为同样大小的页框，用页表记录页号到页框号的映射。逻辑地址分为页号和页内偏移两部分。
例如页大小为 4 KB（2¹² 字节）时，逻辑地址的低 12 位是页内偏移，其余高位是页号。
分页消除了外部碎片，但进程的最后一页可能存在内部碎片。TLB 是页表项的高速缓存，命中时无需再访问内存中的页表。
虚拟内存只把需要的页调入内存。访问不在内存中的页会触发缺页中断，由操作系统从磁盘调入。内存不足时需要页面置换：FIFO 实现简单，但可能出现 Belady 异常；LRU 淘汰最久未使用的页，效果通常较好，但实现成本较高。
