# HTTP 状态码速记

关键词：HTTP 状态码 200 301 400 401 403 404 500

## 分类
HTTP 响应状态码使用三位数字。1xx 表示信息响应，2xx 表示成功，3xx 表示重定向，4xx 表示客户端错误，5xx 表示服务器错误。

## 常见状态码
- 200 OK：请求成功，具体含义取决于请求方法。
- 301 Moved Permanently：资源已永久迁移到新的位置。
- 400 Bad Request：请求存在格式等问题，服务器无法或不愿处理。
- 401 Unauthorized：需要有效的身份认证凭据。
- 403 Forbidden：服务器理解请求，但拒绝执行。
- 404 Not Found：未找到目标资源，或服务器不愿披露其存在。
- 500 Internal Server Error：服务器遇到未预料的情况，无法完成请求。

## 易错点
401 与 403 不能简单混为一谈：前者与有效认证凭据有关，后者表示拒绝执行请求。
状态码不能直接证明网站是否安全，也不能单凭 500 判断是哪一行代码出错。
